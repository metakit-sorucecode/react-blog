# server-node와 통신하는 React 블로그 라이브코딩 따라치기

## 준비

- 서버: cd server-node, npm start (8080)
- 서버 데이터 초기화: db.json을 지우고 다시 실행
- 프론트: cd react-blog, npm run dev (5173)
- 프론트 포트는 5173만 쓴다. 서버 CORS가 5173만 허용한다
- 브라우저: http://localhost:5173
