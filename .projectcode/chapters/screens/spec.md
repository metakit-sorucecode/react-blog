# screens 화면 그리기와 라우트

종류: 기능
배울 것: 화면 7개 정적 마크업, 라우트 연결, grid 글 목록

## 할 일
- S1 홈에 예시 글 카드 3개가 grid로 놓인다. 카드에는 제목1, 제목2, 제목3이 보인다
- S2 카드 제목을 누르면 상세 화면(/board/1)으로 간다
- S3 상세 화면에 제목, 작성자, 내용, 수정과 삭제 버튼, 댓글 목록, 댓글 입력이 보인다
- S4 상세의 수정 버튼을 누르면 수정 화면(/update-form/1)으로 간다
- S5 글쓰기 화면(/save-form)에 제목과 내용 입력칸, 글쓰기 버튼이 보인다
- S6 수정 화면에 제목과 내용 입력칸, 수정하기 버튼이 보인다
- S7 로그인 화면(/login-form)에 아이디와 비밀번호 입력칸, 로그인 버튼이 보인다
- S8 회원가입 화면(/join-form)에 아이디, 비밀번호, 이메일 입력칸, 가입하기 버튼이 보인다
- S9 내 정보 화면(/user-info)에 아이디(읽기만), 이메일, 새 비밀번호 입력칸, 수정하기 버튼이 보인다
- S10 헤더 메뉴를 누르면 각 화면이 헤더 아래에 보인다

## 화면
```
상세 /board/1
+------------------------------------------+
| 제목1                                     |
| 작성자 ssar                               |
| 내용1                                     |
| [수정] [삭제]                             |
| ---------------------------------------- |
| 댓글                                      |
| cos  댓글1                       [휴지통] |
| love 댓글2                       [휴지통] |
| [댓글을 입력하세요________] [등록]        |
+------------------------------------------+

글쓰기 /save-form, 수정 /update-form/1
+------------------------------------------+
| 글쓰기            (수정 화면은 글 수정)   |
| [제목______________________]              |
| [내용______________________]              |
| [                          ]              |
| [글쓰기]          (수정 화면은 수정하기)  |
+------------------------------------------+

로그인 /login-form
+------------------------------------------+
| 로그인                                    |
| [아이디____________]                      |
| [비밀번호__________]                      |
| [로그인]                                  |
+------------------------------------------+

회원가입 /join-form
+------------------------------------------+
| 회원가입                                  |
| [아이디____________]                      |
| [비밀번호__________]                      |
| [이메일____________]                      |
| [가입하기]                                |
+------------------------------------------+

내 정보 /user-info
+------------------------------------------+
| 내 정보                                   |
| [ssar______________] (읽기만)             |
| [이메일____________]                      |
| [새 비밀번호_______]                      |
| [수정하기]                                |
+------------------------------------------+
```

## 흐름
홈 -> 카드 제목 클릭 -> 상세 -> 수정 클릭 -> 수정 화면
헤더 메뉴 클릭 -> 주소 바뀜 -> 헤더 아래에 그 화면

## 안 하는 것
- 겹치는 마크업 나누기: component-split 장
- 서버 데이터로 바꾸기: board-list 장부터
- 버튼 누를 때 동작(제출, 삭제, 새로고침 막기): 미룸. 각 폼 장에서 붙인다
- 없는 주소 안내 화면: error-handling 장
