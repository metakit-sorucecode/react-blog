# board-list 글 목록

종류: 기능
배울 것: axios GET, useEffect로 서버 데이터 그리기

## 할 일
- S1 홈에 들어가면 서버에서 첫 페이지 글 목록(GET /?page=0)을 받아 카드로 그린다. 시드 상태에서는 제목4, 제목3, 제목2가 이 순서로 보인다
- S2 목록을 받기 전에는 카드가 하나도 없는 빈 목록이다
- S3 카드 제목을 누르면 그 글 번호의 상세 주소로 간다. 제목4를 누르면 /board/4다

## 흐름
홈 들어옴 -> 빈 목록 -> 서버에 목록 요청 -> 응답의 글 목록 기억 -> 카드로 그림 -> 제목 클릭 -> /board/글번호

## 안 하는 것
- 상세에 받은 글 보여주기: board-detail 장. 이 장에서 상세는 아직 예시 글자다
- 이전, 다음 페이지와 검색: paging-search 장
- 받는 동안 로딩 표시, 요청 실패 안내: error-handling 장
- 서버 주소를 한 곳에 모으기: board-save 장
