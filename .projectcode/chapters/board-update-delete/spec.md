# board-update-delete 글 수정과 삭제

종류: 기능
배울 것: owner로 버튼 보이기, 기존 값 채운 폼, PUT과 DELETE

## 할 일
- S1 상세에서 owner가 true인 글에만 수정, 삭제 버튼이 보인다. ssar로 로그인하면 /board/1에는 보이고 /board/4에는 보이지 않는다. 로그인 전에는 어느 글에도 보이지 않는다
- S2 수정 화면에 들어가면 주소의 글 번호로 상세를 받아 제목과 내용 칸을 채운다. /update-form/1이면 제목1, 내용1이 채워진다
- S3 수정 화면에서 제목과 내용을 고치면 화면이 고친 값을 기억한다
- S4 수정하기를 누르면 고친 제목과 내용을 서버에 보내고 그 글 상세로 간다. 상세에 고친 제목과 내용이 보인다
- S5 상세에서 삭제를 누르면 서버에서 글을 지우고 홈으로 간다. 목록에 그 글이 없다

## 요청과 응답
PUT /api/boards/:id
요청 헤더: Authorization: Bearer eyJhbGciOi...
요청: { "title": "고친 제목", "content": "고친 내용" }
응답 body: { "id": 1, "title": "고친 제목", "content": "고친 내용" }

DELETE /api/boards/:id
요청 헤더: Authorization: Bearer eyJhbGciOi...
응답 body: null

## 흐름
수정: 내 글 상세 -> 수정 클릭 -> /update-form/글번호 -> 상세 받아 칸 채움 -> 고침 -> 수정하기 클릭 -> 서버에 수정 -> 그 글 상세로 이동 -> 고친 글
삭제: 내 글 상세 -> 삭제 클릭 -> 서버에서 삭제 -> 홈으로 이동 -> 목록에 그 글 없음

## 그대로인 것
- 목록, 글쓰기, 회원가입, 로그인의 동작과 모습은 바뀌지 않는다
- 상세의 댓글 목록과 댓글 입력은 그대로 보인다

## 안 하는 것
- 삭제 전 확인 창: 미룸
- 수정 화면의 취소 버튼: 안 만듦
- 댓글 삭제 버튼을 owner인 댓글에만 보이기: reply 장
- 빈 제목과 내용 막기: form-hook 장
- 수정과 삭제 실패 안내: error-handling 장
- 남의 글 수정 화면 막기: auth-guard 장
- 버튼 중복 클릭 막기: 미룸
