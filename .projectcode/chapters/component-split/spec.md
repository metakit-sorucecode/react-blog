# component-split 겹치는 화면을 컴포넌트로

종류: 리팩터
배울 것: 컴포넌트 분리, props, children, props 펼침, map

## 할 일
- S1 홈의 글 카드 3개를 글 카드 조각 하나로 그린다. 글 목록 배열을 돌며 카드마다 번호와 제목을 넘긴다
- S2 상세의 댓글 줄 2개를 댓글 줄 조각 하나로 그린다. 댓글 배열을 돌며 작성자와 내용을 넘긴다
- S3 폼 5개가 카드 틀과 제목 줄을 폼 틀 조각 하나로 쓴다. 제목 글자는 props로, 안의 입력칸과 버튼은 children으로 넘긴다
- S4 입력칸을 입력칸 조각 하나로 그린다. 받은 속성(종류, 안내 글자, 값, 읽기만)을 펼쳐서 그대로 넘긴다

## 그대로인 것
- 모든 화면의 모습과 동작은 바뀌지 않는다
- 주소, 메뉴, 카드에서 상세로 가기, 상세에서 수정으로 가기가 그대로다
- screens 장 테스트가 그대로 통과한다

## 안 하는 것
- 헤더 메뉴 5개를 배열과 map으로 바꾸기: 안 만듦. 3장 화면이 아니고 login 장에서 로그인 여부에 따라 메뉴를 바꾼다
- 내용 입력칸(여러 줄) 조각: 안 만듦. 글쓰기와 수정 두 곳뿐이다
- 글쓰기와 수정 폼을 한 조각으로 합치기: 안 만듦. 뒤 장에서 입력값이 들어오면 화면 파일 하나에서 읽히는 편이 쉽다
- 상세의 수정, 삭제 버튼 조각: 안 만듦. 한 번만 쓴다
