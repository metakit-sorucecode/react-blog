# login 로그인

종류: 기능
배울 것: 응답 헤더 토큰, zustand 로그인 상태, 헤더 메뉴 바꾸기, 로그아웃

## 할 일
- S1 아이디와 비밀번호를 입력하고 로그인을 누르면 입력한 값을 서버(POST /login)에 보낸다. 화면은 새로고침되지 않는다. ssar, 1234를 넣으면 그 두 값이 간다
- S2 로그인에 성공하면 응답 헤더 Authorization의 토큰과 입력한 아이디를 로그인 상태로 기억하고 홈으로 간다
- S3 로그인 전 헤더 메뉴는 홈, 로그인, 회원가입이다
- S4 로그인 뒤 헤더 메뉴는 홈, 글쓰기, 내 정보, 로그아웃이고 메뉴 끝에 ssar님이 보인다
- S5 로그아웃을 누르면 로그인 상태를 비우고 홈으로 간다. 헤더 메뉴가 로그인 전으로 돌아간다

## 흐름
입력 -> 로그인 클릭 -> 서버에 로그인 요청 -> 성공 응답 헤더에서 토큰 꺼내기 -> 로그인 상태에 토큰과 아이디 기억 -> 홈 -> 헤더 메뉴가 로그인 뒤 메뉴로
로그아웃 클릭 -> 로그인 상태 비우기 -> 홈 -> 헤더 메뉴가 로그인 전 메뉴로

## 안 하는 것
- 새로고침해도 로그인 유지: login-keep 장
- 기억한 토큰을 요청에 붙이기: board-save 장
- 아이디나 비밀번호가 틀렸을 때 안내: error-handling 장
- 빈칸 검사: validation 장
- 로그인한 뒤 로그인, 회원가입 화면 막기: 미룸
- 로그인하지 않고 글쓰기, 내 정보 주소로 들어오기 막기: auth-guard 장
