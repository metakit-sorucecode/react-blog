# board-save 글쓰기

종류: 기능
배울 것: axios 인스턴스와 인터셉터로 토큰 보내기

## 할 일
- S1 글쓰기 화면에서 제목과 내용을 입력하면 화면이 값을 기억한다
- S2 로그인한 뒤 글쓰기를 누르면 제목과 내용을 로그인 토큰과 함께 서버에 보낸다
- S3 글이 저장되면 홈으로 가고 새 글이 목록 맨 위에 보인다
- S4 로그인한 뒤에는 앞에서 만든 글 목록과 상세 요청에도 토큰이 붙는다

## 요청과 응답
POST /api/boards
요청 헤더: Authorization: Bearer eyJhbGciOi...
요청: { "title": "새 제목", "content": "새 내용" }
응답 body: { "id": 5, "title": "새 제목", "content": "새 내용" }

## 흐름
제목과 내용 입력 -> 값 기억 -> 글쓰기 클릭 -> 요청에 토큰 붙이기 -> 서버에 저장 -> 홈으로 이동 -> 새 글이 목록 맨 위에

## 그대로인 것
- 목록, 상세, 회원가입, 로그인의 동작과 모습은 바뀌지 않는다

## 안 하는 것
- 빈 제목과 내용 막기: validation 장
- 저장 실패 안내: error-handling 장
- 로그인 전 글쓰기 화면 막기: auth-guard 장
- 버튼 중복 클릭 막기: 미룸
- 글 수정 화면에서 보내기: board-update-delete 장
