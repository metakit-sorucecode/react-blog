# layout 레이아웃과 헤더

종류: 기능
배울 것: Layout과 Outlet, 헤더 메뉴, NavLink로 지금 메뉴 강조, Tailwind와 DaisyUI 최소 스타일

## 할 일
- S1 홈 주소(/)에 들어가면 맨 위에 헤더가 보이고 그 아래에 홈 화면이 보인다
- S2 헤더와 홈 화면은 화면 가장자리에서 여백을 두고 놓인다
- S3 헤더에 홈, 로그인, 회원가입, 글쓰기, 내 정보 메뉴가 보인다
- S4 메뉴를 누르면 그 주소로 간다. 로그인 /login-form, 회원가입 /join-form, 글쓰기 /save-form, 내 정보 /user-info
- S5 지금 보고 있는 화면의 메뉴가 강조된다. 홈에서는 홈 메뉴만 강조된다

## 화면
```
+------------------------------------------------+
|                                                |
|  [홈]  로그인  회원가입  글쓰기  내 정보        |
|  ------------------------------------------    |
|  홈                                            |
|                                                |
+------------------------------------------------+
[홈]은 강조된 메뉴
```

## 흐름
주소 / 접속 -> 레이아웃이 헤더를 그림 -> 헤더 아래 자리에 홈 화면 -> 메뉴 클릭 -> 주소 바뀜 -> 지금 메뉴 강조

## 안 하는 것
- 로그인, 회원가입, 글쓰기, 내 정보 화면: screens 장
- 없는 주소 안내 화면: 미룸. error-handling 장
- 로그인 여부에 따라 메뉴 바꾸기: login 장
- 좁은 화면에서 메뉴 접기: 안 만듦
