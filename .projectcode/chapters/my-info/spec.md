# my-info 내 정보 수정

종류: 기능
배울 것: 조회한 값으로 폼 채우기, PUT

## 할 일
- S1 내 정보 화면에 들어가면 서버에서 내 정보를 받아 아이디와 이메일 칸을 채운다. ssar로 로그인하면 ssar, ssar@nate.com이 채워진다. 아이디 칸은 고칠 수 없고 새 비밀번호 칸은 비어 있다
- S2 이메일과 새 비밀번호 칸을 고치면 화면이 고친 값을 기억한다
- S3 수정하기를 누르면 이메일과 새 비밀번호를 서버에 보내고 홈으로 간다. 내 정보에 다시 들어오면 바뀐 이메일이 보인다
- S4 새 비밀번호를 넣어 수정하면 로그아웃 뒤 새 비밀번호로 로그인된다
- S5 새 비밀번호를 비워 수정하면 비밀번호는 그대로다. 로그아웃 뒤 원래 비밀번호로 로그인된다

## 요청과 응답
GET /api/user
요청 헤더: Authorization: Bearer eyJhbGciOi...
응답 body: { "id": 1, "username": "ssar", "email": "ssar@nate.com" }

PUT /api/user
요청 헤더: Authorization: Bearer eyJhbGciOi...
요청: { "email": "ssar@gmail.com", "password": "" }
응답 body: { "id": 1, "username": "ssar", "email": "ssar@gmail.com" }

## 흐름
내 정보 메뉴 -> 서버에서 내 정보 받음 -> 아이디와 이메일 칸 채움 -> 이메일과 새 비밀번호 고침 -> 수정하기 클릭 -> 서버에 수정 -> 홈으로 이동 -> 내 정보에 다시 들어오면 바뀐 이메일

## 그대로인 것
- 내 정보 화면의 모습은 바뀌지 않는다. 아이디 칸만 예시 글자 대신 받은 값을 보인다
- 목록, 상세, 글쓰기, 글 수정, 회원가입, 로그인의 동작과 모습은 바뀌지 않는다

## 안 하는 것
- 새 비밀번호 확인 칸: 안 만듦
- 이메일 형식 검사: 안 만듦
- 로그인 전 내 정보 화면에 로그인 안내: auth-guard 장
- 내 정보 조회와 수정 실패 안내: error-handling 장
- 버튼 중복 클릭 막기: 미룸
