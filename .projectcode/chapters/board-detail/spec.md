# board-detail 글 상세

종류: 기능
배울 것: useParams, 상세와 댓글 목록 그리기

## 할 일
- S1 상세 주소에 들어가면 주소의 글 번호로 서버에서 상세(GET /api/boards/:id)를 받는다. /board/4면 4번 글을 받는다
- S2 받은 제목, 작성자, 내용을 그린다. /board/4에서는 제목4, 작성자 love, 내용4가 보인다
- S3 받은 댓글 목록을 작성자와 댓글로 그린다. /board/4에서는 ssar 댓글1, ssar 댓글2, cos 댓글3이 이 순서로 보인다
- S4 상세를 받기 전에는 예시 글자가 없고 제목, 내용, 댓글이 비어 있다
- S5 수정 버튼을 누르면 그 글 번호의 수정 주소로 간다. /board/4에서 누르면 /update-form/4다

## 흐름
목록에서 제목 클릭 -> /board/글번호 -> 빈 상세 -> 주소에서 글 번호 꺼냄 -> 서버에 상세 요청 -> 응답의 글 기억 -> 제목, 작성자, 내용, 댓글 그림

## 안 하는 것
- 댓글이 없을 때 안내: 안 만듦
- 내 글일 때만 수정, 삭제 버튼 보이기: board-update-delete 장. 이 장에서는 버튼이 늘 보인다
- 삭제 버튼, 댓글 휴지통, 댓글 등록 동작: board-update-delete, reply 장
- 수정 화면에 기존 값 채우기: board-update-delete 장
- 받는 동안 로딩 표시, 없는 글 안내: error-handling 장
