# project-setup 출발점 (강의 전 준비)

종류: 기능
배울 것: 실행 방법, 폴더 구조

## 할 일
- S1 start 프로젝트를 복사한 react-blog 폴더에서 개발 서버를 띄우면 5173 주소에 Hello World가 보인다
- S2 Hello World는 흰 바탕에 큰 굵은 검정 글자로 보인다. 스타일 도구가 연결됐다는 확인이다
- S3 소스 폴더에는 코드 파일 두 개와 스타일 파일 하나만 있고 코드 파일은 모두 .jsx다
- S4 옛 코드, 예제 데이터, 빌드 결과, 옛 안내 문서가 남아 있지 않다
- S5 포맷 명령 하나로 코드 모양을 맞춘다
- S6 루트에서 테스트 명령 하나로 서버와 프론트를 함께 띄워 확인한다

## 흐름
start 복사 -> 옛 코드 지우기 -> Hello World 화면 -> 개발 서버 실행 -> 브라우저에 Hello World

## 안 하는 것
- 레이아웃과 헤더: layout 장
- 라우터 연결: layout 장
- 학생이 쓰는 테스트 설정: 안 만듦
- 라이브러리 정리: 안 만듦. package.json의 의존성과 node_modules는 그대로 둔다
- 탭 제목과 light 테마: start에 이미 있어 그대로 둔다
