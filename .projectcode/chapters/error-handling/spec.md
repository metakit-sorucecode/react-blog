# error-handling 에러 처리

종류: 기능
배울 것: isPending 로딩, isError로 없는 글 안내, 응답 인터셉터에서 sonner 토스트, 없는 주소 안내, 다시 시도 규칙

## 할 일
- S1 홈, 상세, 글 수정, 내 정보 화면이 데이터를 받는 동안 로딩 표시를 보인다
- S2 없는 글 상세(/board/9999)에 들어가면 게시글이 없다는 안내와 목록으로 가는 링크를 보인다. 404는 다시 묻지 않아 바로 보이고, 토스트는 뜨지 않는다
- S3 이미 있는 아이디로 가입하면 "이미 존재하는 유저네임입니다" 토스트가 뜨고 회원가입 화면에 남는다
- S4 비밀번호가 틀린 채 로그인하면 "아이디 또는 비밀번호가 틀렸습니다" 토스트가 뜨고 로그인 화면에 남는다
- S5 남의 글 수정 화면에서 수정하기를 누르면 "권한이 없습니다" 토스트가 뜨고 수정 화면에 남는다
- S6 서버에 연결할 수 없으면 조회든 쓰기든 "서버에 연결할 수 없습니다" 토스트가 한 번 뜬다
- S7 조회가 500으로 실패하거나 응답이 없으면 한 번만 다시 묻는다. 400대로 실패하면 다시 묻지 않는다
- S8 없는 주소(/abc)에 들어가면 헤더 아래에 페이지를 찾을 수 없다는 안내와 홈으로 가는 링크를 보인다

## 화면
로딩 (홈, 상세, 글 수정, 내 정보 공통)
+--------------------------------------+
| 홈  글쓰기  내 정보  로그아웃  ssar님 |
|--------------------------------------|
|              (빙글 도는 표시)          |
+--------------------------------------+

없는 글
+--------------------------------------+
| 홈  글쓰기  내 정보  로그아웃  ssar님 |
|--------------------------------------|
| 게시글이 없습니다                      |
| [ 목록으로 ]                          |
+--------------------------------------+

없는 주소
+--------------------------------------+
| 홈  로그인  회원가입                   |
|--------------------------------------|
| 페이지를 찾을 수 없습니다              |
| [ 홈으로 ]                            |
+--------------------------------------+

토스트 (화면 위 오른쪽. 검정 바탕, 흰 글자, 테두리 없음. 오른쪽 아래는 Devtools 버튼 자리)
+--------------------------------------+
|        [ 이미 존재하는 유저네임입니다 ]|
|              회원가입                  |
+--------------------------------------+

## 흐름
요청 -> 기다리는 동안 로딩 -> 실패 -> 400대는 바로 실패, 500과 연결 실패는 한 번 더 묻기 -> 조회 실패는 화면이 안내, 쓰기 실패와 연결 실패는 토스트 -> 그 화면에 남음

## 안 하는 것
- 쓰는 동안 버튼 로딩과 중복 클릭 막기: 미룸
- 토큰 만료와 401 자동 로그아웃: 미룸
- 없는 글의 수정 화면 안내: 미룸
- 목록, 글 수정, 내 정보 조회가 응답을 받고 실패할 때의 화면 안내: 안 만듦. 지금 서버에서 이런 실패는 없는 글뿐이다
- 요청 시간 제한: 안 만듦. 서버가 응답 없이 멈추는 경우는 server-node를 고쳐야 생긴다
- 500 응답을 수업에서 직접 보이기: 안 만듦. server-node 수정이 필요하다
