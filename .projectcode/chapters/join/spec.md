# join 회원가입

종류: 기능
배울 것: useState 폼, axios POST, 성공하면 이동

## 할 일
- S1 아이디, 비밀번호, 이메일을 입력하고 가입하기를 누르면 입력한 값을 서버(POST /join)에 보낸다. 화면은 새로고침되지 않는다. kim, 1234, kim@nate.com을 넣으면 그 세 값이 간다
- S2 가입에 성공하면 회원가입 완료 안내를 띄운다
- S3 안내를 닫으면 로그인 화면(/login-form)으로 간다

## 흐름
입력 -> 값 기억 -> 가입하기 클릭 -> 서버에 가입 요청 -> 성공 응답 -> 회원가입 완료 안내 -> 로그인 화면

## 안 하는 것
- 비밀번호 확인 칸: 안 만듦
- 중복 아이디 같은 실패 안내: error-handling 장
- 빈칸, 이메일 형식 검사: validation 장
- 공백만 입력한 값 막기, 버튼 중복 클릭 막기: 미룸
- 로그인: login 장
