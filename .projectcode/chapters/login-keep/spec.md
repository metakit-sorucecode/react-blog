# login-keep 로그인 유지

종류: 기능
배울 것: localStorage, jwt-decode로 복원

## 할 일
- S1 로그인에 성공하면 받은 토큰을 브라우저 저장소에 남긴다. 브라우저를 닫았다 열어도 남는 곳이다
- S2 앱이 시작할 때 저장된 토큰이 있으면 토큰 안의 아이디를 꺼내 로그인 상태를 되살린다. ssar로 로그인한 뒤 새로고침해도 헤더 메뉴가 홈, 글쓰기, 내 정보, 로그아웃이고 ssar님이 보인다
- S3 로그아웃하면 저장한 토큰을 지운다. 새로고침해도 헤더 메뉴가 홈, 로그인, 회원가입이다

## 흐름
로그인 성공 -> 토큰을 저장소에 남기기 -> 새로고침 -> 앱 시작 -> 저장소에서 토큰 꺼내기 -> 토큰 안의 아이디 꺼내기 -> 로그인 상태 되살리기 -> 헤더 메뉴가 로그인 뒤 메뉴로
로그아웃 클릭 -> 로그인 상태 비우기 -> 저장소의 토큰 지우기 -> 새로고침해도 로그인 전 메뉴

## 저장과 토큰 예시
브라우저 저장소: jwt = "Bearer eyJhbGciOi..."
토큰 안의 내용: { "id": 1, "username": "ssar", "iat": ..., "exp": ... }

## 안 하는 것
- 저장된 토큰이 망가졌을 때 지우고 로그인 전으로 시작하기: 미룸
- 토큰 만료 확인: 미룸
- 다른 탭의 로그인, 로그아웃 따라가기: 안 만듦
- 기억한 토큰을 요청에 붙이기: board-save 장
