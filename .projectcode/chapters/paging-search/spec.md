# paging-search 페이징과 검색

종류: 기능
배울 것: queryKey에 page와 keyword, 이전 화면 유지

## 할 일
- S1 홈 목록 아래에 이전, 다음 버튼과 쪽 번호(1 / 2)를 보인다. 첫 페이지에서는 이전이 막힌다
- S2 다음을 누르면 다음 페이지 글을 보이고 쪽 번호가 바뀐다. 마지막 페이지에서는 다음이 막힌다
- S3 이전을 누르면 앞 페이지 글을 보인다
- S4 목록 위 검색창에 칠 때마다 제목에 그 글자가 든 글만 보인다. 검색어가 바뀌면 첫 페이지부터 보인다
- S5 검색 결과가 없으면 목록 자리에 "검색 결과가 없습니다"를 보인다
- S6 새 목록을 받는 동안 이전 목록과 검색창이 그대로 보인다. 로딩 표시로 바뀌지 않아 검색창의 글자와 커서가 남는다
- S7 페이지와 검색어마다 따로 캐시에 담는다. 1분 안에 본 페이지로 돌아가면 요청 없이 바로 보인다
- S8 글을 쓰거나 고치거나 지우면 모든 페이지와 검색 결과의 캐시를 무효화한다. 글을 쓴 뒤 홈에서 다음을 누르면 2페이지를 다시 받는다

## 화면
홈 (시드 글 4개, 한 페이지 3개)
+--------------------------------------+
| 홈  로그인  회원가입                   |
|--------------------------------------|
| [ 제목 검색_______________ ]          |
| +--------+ +--------+ +--------+     |
| | 제목4  | | 제목3  | | 제목2  |     |
| +--------+ +--------+ +--------+     |
|       [ 이전 ]  1 / 2  [ 다음 ]       |
+--------------------------------------+

검색 결과 없음
+--------------------------------------+
| 홈  로그인  회원가입                   |
|--------------------------------------|
| [ 없는글__________________ ]          |
| 검색 결과가 없습니다                   |
|       [ 이전 ]  1 / 1  [ 다음 ]       |
+--------------------------------------+

## 흐름
검색어 입력이나 이전, 다음 클릭 -> 목록 키가 바뀜 -> 캐시에 있으면 바로 그림, 없으면 이전 목록을 보인 채 받음 -> 새 목록과 쪽 번호

## 그대로인 것
- 처음 홈에 들어올 때는 지금처럼 로딩 표시를 보인다

## 안 하는 것
- 페이지와 검색어를 주소에 남기기: 안 만듦. 홈에 돌아오면 1페이지에 빈 검색창이다
- 받는 동안 목록을 흐리게 표시: 안 만듦
- 입력이 멈춘 뒤 요청하기: search-debounce 장
